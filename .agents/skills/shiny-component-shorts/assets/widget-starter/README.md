# Plotly widget starter

This template proves one behavior: a Shiny input updates an existing Plotly widget, so Plotly keeps its hover and legend controls.

Copy this directory into a new production after you bootstrap the pinned skill. Replace the sample task and data with the widget example you want to show. Keep one behavior, one short source excerpt, and the live app on screen for most of the video.

Record the actions in `actions.yaml` as continuous footage. Split that recording into the three clips named in `interaction-shot.yaml`. Build the stills from `source-shots.yaml`, then interleave the clips and stills in `editorial.yaml`.

The narration is a complete timing target. Copy `narration.txt` to `artifacts/narration.txt` in the production. Generate and measure the audio before you record. Check every cue against the measured word timing.
